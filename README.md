## About me

Hey! I'm Cloudy, an 18-year-old developer working primarily with Unreal Engine 5.

My journey in game development started at the age of ten, when I created a simple 2D game using Pocket Code. A few years later, I experimented with Unity and C#, building a small prototype of a warfare game at the age of twelve or thirteen.

At fifteen, I discovered Unreal Engine and its Blueprint system. At the time, I wasn't particularly interested in programming, but working with Unreal gradually changed that. I started with Unreal Engine 5.0 shortly after its release and have been learning and building with the engine ever since, now working with the latest versions of UE5.

Today, I'm a student focused on building a strong foundation in game development, software development, and computer science. I'm still learning, experimenting, and improving - with a particular interest in Unreal Engine and the technical side of game development.
